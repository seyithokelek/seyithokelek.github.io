zFinder is a spectral analysis software developed to measure the redshift (z) value of quasar spectra.
The code compares the observed spectrum with a quasar template across the entire wavelength range, evaluating both the continuum structure and
strong emission lines simultaneously. Rather than relying solely on the classical cross-correlation approach, it aims to achieve a more reliable
and accurate z measurement by utilizing additional statistical fitting parameters.
